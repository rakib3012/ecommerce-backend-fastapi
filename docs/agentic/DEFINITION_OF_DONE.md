# Definition of Done

- [ ] Requirement and PRD traceability documented.
- [ ] Acceptance criteria and edge cases written.
- [ ] Existing code pattern inspected.
- [ ] Architecture and naming preserved.
- [ ] Endpoint/schema/service/model boundaries respected.
- [ ] Auth/RBAC/ownership enforced.
- [ ] Pricing and money precision correct.
- [ ] Transaction, rollback, inventory and idempotency reviewed.
- [ ] Constraints/indexes/FKs reviewed.
- [ ] Alembic migration manually inspected and tested where possible.
- [ ] Unit/service/API/regression tests added and executed.
- [ ] Concurrency/idempotency tests added when relevant.
- [ ] Configured lint/type/build checks run or marked NOT RUN.
- [ ] Independent code review complete; no Critical/High findings.
- [ ] Security review complete for sensitive changes.
- [ ] Docs updated.
- [ ] Final diff checked; exact commands/results and risks reported.
